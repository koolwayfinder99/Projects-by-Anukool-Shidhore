## 🎓 How to Use This Project

### Installation (5 minutes)
```bash
pip install -r requirements.txt
```

### Quick Detection (2 minutes)
```python
from scripts.vision_transformer_inference import VisionTransformerSegmentation
pipeline = VisionTransformerSegmentation()
detections = pipeline.detect_objects("robot.jpg")
```

### Data Augmentation (2 minutes)
```python
from scripts.diffusion_augmentation import DiffusionAugmentationPipeline
augmentor = DiffusionAugmentationPipeline()
results = augmentor.augment_dataset("data/input", "data/output")
```

### Batch Processing (5 minutes)
```python
results = pipeline.process_batch("data/images", "outputs/")
print(f"Detected: {len(results['detections'])} objects")
```
